Grammar & Operator Precedence

Grammar used by the parser
E  → T E′
E′ → + T E′ | - T E′ | ε
T  → F T′
T′ → * F T′ | / F T′ | ε
F  → (E) | id | number
Precedence order

1. Parentheses — highest
2. Multiplication and division
3. Addition and subtraction — lowest

The grammar removes left recursion so each non-terminal can be implemented as a recursive-descent function.
